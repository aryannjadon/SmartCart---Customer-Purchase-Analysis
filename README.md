# SmartCart - Customer Purchase Analysis

## About the Project

This project focuses on analyzing customer purchase data to understand buying behavior. The goal is to find useful patterns like popular products, customer trends, and sales insights.

---

## What I Did

* Cleaned and processed the dataset using Pandas
* Analyzed customer purchase patterns
* Identified frequently bought products
* Performed basic data visualization to understand trends
* Extracted insights that can help improve sales

---

## Tech Used

Python, Pandas, NumPy, Matplotlib

---

## Result

The analysis helped in identifying customer preferences and top-selling products. It also showed patterns that can help businesses improve their strategy.

---

## Why this Project

This project helped me improve my data analysis skills and understand how real-world business data can be used for decision-making.
